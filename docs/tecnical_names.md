# Lista de Termos Técnicos em Inglês para Elementos da Construção Civil

## 🏗️ Elementos Estruturais

- **Pilar** → Column
- **Viga** → Beam
- **Viga principal / viga mestre** → Girder
- **Laje** → Slab
- **Laje plana** → Flat slab / Flat plate
- **Laje nervurada** → Waffle slab
- **Vigota** → Joist
- **Capitel (em lajes)** → Shearhead / Drop panel
- **Vão** → Span
- **Nó estrutural** → Joint
- **Grelha** → Frame structure

## 🧱 Fundação

- **Sapata** → Footing
- **Estaca** → Pile
- **Estaca de ponte / pilar de ponte** → Pier
- **Fundação** → Foundation
- **Culée (apoio de ponte)** → Abutment

## 🛣️ Infraestrutura e Vias

- **Via / Estrada** → Road
- **Pavimento / Pavimentação** → Pavement
- **Travessia / Vão de ponte** → Span
- **Muro de contenção** → Retaining wall

## 🧱 Materiais de Construção

- **Concreto / Betão** → Concrete
- **Concreto armado** → Reinforced concrete
- **Concreto protendido** → Prestressed concrete
- **Cimento** → Cement
- **Aço** → Steel
- **Armadura / Ferro** → Rebar (reinforcing bar)
- **Granulato / Brita / Agregado** → Aggregate

## ⚙️ Esforços e Comportamento Estrutural

- **Carga** → Load
- **Carga pontual** → Point load
- **Carga distribuída** → Uniform load
- **Flexão** → Flexure
- **Cisalhamento** → Shear
- **Torção** → Torsion
- **Compressão** → Compression
- **Tração** → Tension
- **Tensão (mecânica)** → Stress
- **Deformação** → Deflection
- **Flambagem** → Buckling
- **Excentricidade** → Eccentricity

## 🔧 Elementos Diversos

- **Andaime** → Scaffolding
- **Telhado** → Roof
- **Torneira** → Tap
- **Tomada** → Outlet
- **Disjuntor** → Circuit breaker
